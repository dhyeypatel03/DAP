# My Portfolio

This is my personal portfolio website showcasing my **projects**, **skills**, and **YouTube content**.  
Built with **React**, **GSAP animations**, and responsive design.

## Features
- Interactive headings with text effects
- GitHub projects showcase
- Embedded YouTube videos
- Contact form and links to socials
- Responsive layout for desktop and mobile
